# Tableau Guide
- Connect → Text File → choose `cleaned_tableau_data.csv`
- Build a KPI worksheet using a numeric field and SUM aggregation
- Build a bar chart with a category on Columns and a numeric measure on Rows
- If a date field exists, build a line chart by month
- Dashboard → New Dashboard; drag worksheets onto it and add filters
- Tableau Public workbooks may be public: avoid confidential data
